# 预测分析场景规则与多场景展示

> 配套实现：`backend/services/analysis_scenarios.py`、`ensemble.predict`、赛事详情页。  
> 整理日期：2026-09-07  
> **声明**：各场景输出仅供竞技分析，不构成投注建议。

---

## 1. 场景枚举

| ID | 名称 | 权重形态 | 说明 |
|----|------|----------|------|
| `ensemble` | 整合版 | 分联赛/全局融合权重 | 旗舰结论 |
| `elo` | 实力对比（ELO） | elo=1 | 无比分矩阵 |
| `poisson` | 进球分布（泊松） | poisson=1 | λ + 比分矩阵主路径 |
| `xg` | 过程质量（xG） | xg=1 | 需射门统计覆盖 |
| `monte_carlo` | 波动模拟（MC） | monte_carlo=1 | 吃泊松/xG 的 λ |

一次预测会算出全部场景胜平负，写入 `meta_json.scenarios`；**顶栏主结论**按规则自动选一个场景（可配置关闭）。

---

## 2. 自动选主结论规则

| 条件 | 主场景 | 理由摘要 |
|------|--------|----------|
| 联赛 ∈ `ESPN_LEAGUE_MAP` 且 `xg_coverage ≥ 0.5` | **ensemble** | 统计管线 + xG 充足 |
| 有 ESPN 且 `0 < xg_coverage < 0.5` | **ensemble** | 覆盖有限仍融合（缺侧已降权） |
| 有 ESPN 且 `xg_coverage ≈ 0` | **poisson** | 避免空 xG 噪声主导 |
| 无 ESPN / 纯 `LS*`（`five00_only`） | **poisson** | 固定泊松主结论；整合/xG 不可用 |

配置（`config.yaml` → `ensemble.analysis_scenarios`）：

- `apply_primary: true`（默认）：顶栏字段用主场景结果；`false` 则顶栏始终整合版，场景仅作对照。

可用性标记：`scenarios.*.available`（无 ESPN 时 `ensemble`/`xg` 标为弱可用，仍可浏览数值）。

---

## 3. API / 落库字段

预测结果顶层 + `meta_json`（经 `to_api_dict` 展开）：

| 字段 | 含义 |
|------|------|
| `primary_scenario` | 自动主场景 ID |
| `scenario_reason` | 中文选择理由 |
| `espn_pipeline` | 是否 ESPN 深度映射 |
| `scenarios` | 各场景胜平负、权重、比分线索 |
| `scenario_order` | 展示顺序 |
| `ensemble_probs` | 纯整合版概率快照（主结论切走后仍可对照） |

旧预测无上述字段时，详情页提示「重新计算预测」。

---

## 4. 详情页行为

- 「预测结论」：场景芯片切换浏览；带「主」标记者为落库主结论；不可用场景置灰禁点。
- 「设为主结论并锁定」：写入 `scenario_locked`，下次重算仍保留（场景仍可用时）。
- 浏览非主场景时提示：对照结果 ≠ 落库主结论。
- 「模型细节」图表跟随当前浏览场景的胜平负。
- 列表页展示主结论场景短标签（整合 / 泊松 / ELO…）；缺 `primary_scenario` 视为过期可批量重算。

## 5. 与数据源策略的关系

见 [500与ESPN数据源能力梳理.md](./500与ESPN数据源能力梳理.md)：

- 双源重点 / 扩展联赛 → 默认整合版（xG 充足时）。
- 纯 500（`pipeline_tier=five00_only`）→ **泊松主结论**；`meta_json.five00_only`；整合/xG 不可用。
- EC：ESPN-only，无 xG 时亦泊松。

运维入口：

- 模型管理 → 概览：「一键补齐过期未赛」（含缺场景）
- 模型管理 → 数据质量：「仅重训」「拉取伤病」「扩展联赛补齐」「UEL 补齐」「P0」
