# 500彩票网 — 竞彩足球赛事列表功能分析

> 分析对象：胜平负/让球页 [jczq/?playid=269](https://trade.500.com/jczq/?playid=269&g=2)；混合过关扩展行见 §12 [jczq/?playid=312](https://trade.500.com/jczq/?playid=312&g=2)  
> 对应 DOM 容器：`div.bet-main`（含上方 `div.filter` 筛选栏）  
> 前端模块：`DgSelector` / `DgFilter` / `DgHeader` / `BetSort` / `ExpMenu` / `SPUpdate`（`spf.js` + `jcbase.js`）  
> 分析日期：2026-08-25

---

## 1. 区域范围与结构

赛事列表由 **筛选栏** + **固定表头** + **按日分组的表格体** 三部分组成：

```
div.filter                    ← 控制列表显示/隐藏哪些场次
div.bet-main
├── div#betTbTheadWrap        ← 表头（滚动时吸顶）
│   └── table#betTbThead
├── div.bet-date-wrap         ← 日期分组标题（可折叠）
│   └── table.bet-tb          ← 当日赛事行
├── div.bet-date-wrap
│   └── table.bet-tb
└── ...
div#livetip                   ← 奖金变化浮层（全局）
div#flybetbtnWrap             ← 选号抛物线动画容器
```

表头列宽（colgroup）：

| 列 | 宽度 | 类名 |
|----|------|------|
| 编号 | 80px | `th-no` |
| 赛事 | 90px | `th-evt` |
| 时间 | 100px | `th-endtime` |
| 对阵 | 自适应 | `th-team` |
| 让球 | 50px | `th-rang` |
| 胜/平/负 | 315px | `th-betbtn` |
| 数据 | 80px | `th-data` |
| 百家平均 | 141px | `th-pei`（本页 CSS 隐藏，见 §8） |

## 2. 筛选栏（filter）— 列表可见性控制

筛选栏虽在 `bet-main` 外部，但直接驱动列表行的显示/隐藏，是列表功能的一部分。

### 2.1 快捷筛选

| 筛选项 | ID | 过滤逻辑 |
|--------|-----|----------|
| 五大联赛 | `filter_5dls` | 仅保留 `simpleleague` 为英超/意甲/西甲/德甲/法甲 |
| 奖金1.6倍以下 | `filter_lt16` | 保留 `getMinSp() ≤ 1.6` 的场次（取当前玩法最低 SP） |
| 只看单关 | `filter_dg` | 保留 `data-kdg="1"` 的场次 |
| 显示奖金变化浮层 | `filter_jjfc` | 开启后悬停赔率行才显示历史 SP 浮层 |
| 只看热门 | `filter_rm` | 保留 `ishot=true` 的场次（热门数据异步加载后显示） |
| 已截止 | `filter_end` | 勾选后显示 `data-isend="1"` 的场次；默认隐藏已截止 |

### 2.2 高级筛选（展开 `#filterMore`）

| 维度 | 容器 ID | 逻辑 |
|------|---------|------|
| 联赛筛选 | `league_filters` | 按 `data-simpleleague` 勾选；未勾选的联赛场次隐藏；支持全选/反选 |
| 让球筛选 | `rq_filters` | 按 `data-rangqiu` 值过滤（如 +1、-1、+2） |
| 日期筛选 | `date_filters` | 按 `data-processdate` / 星期几（`data-week`）过滤 |

### 2.3 筛选状态栏

| 元素 | 功能 |
|------|------|
| `filter-evtnums` | 显示当前可见总场次（如「总 14 场比赛」） |
| `filter-end` | 显示已截止场次数（如「已截止 2 场」） |
| `filter-hadhide` | 显示因筛选隐藏场次数；点击关闭图标调用 `clearHide()` 恢复全部 |

### 2.4 URL 参数联动

- 支持 `?league=韩职` 等 URL 参数，页面加载时自动勾选对应联赛并过滤（`filterByUrl`）。

### 2.5 筛选与选号联动

- 被筛掉的场次若已选号，会从投注模型中移除（`model.removeByBets`）。
- 恢复显示时重新 `showBets`。

## 3. 表头功能（betTbThead）

### 3.1 固定表头（吸顶）

- 滚动超过 `#betTbTheadWrap` 顶部时，表头添加 `bet-tb-fixth` 类固定定位。
- 插入占位 shim 元素防止布局跳动。
- 窗口 `onscroll` 实时计算。

### 3.2 开赛时间列 — 三种显示模式

下拉 `#stopTimeToggle` 可切换：

| 模式 | 单元格内容 | title 提示 |
|------|------------|------------|
| 开赛时间 | `matchdate` 的 MM-DD HH:mm | 开赛时刻 |
| 截止时间 | `buyendtime` 的 MM-DD HH:mm | 「xx:xx截止」 |
| 剩余时间 | 倒计时文案 | 「X天X小时」「X分」「即将开始」 |

切换时表头标题与下拉项文字互换。

### 3.3 胜/平/负列 — 奖金排序

胜、平、负三列各自有独立下拉菜单，调用 `sort_spf`：

| 排序项 | 参数 | 说明 |
|--------|------|------|
| 恢复默认排序 | `index` | 按原始场次顺序 |
| 从低到高 | `nspf_3/1/0` 或 `spf_3/1/0` | 按胜平负或让球 SP 升序 |
| 从高到低 | 同上 + `true` | 降序 |
| 从低到高[让] | `spf_*` | 仅让球行 |
| 从高到低[让] | `spf_*` + `true` | 仅让球行降序 |

排序在**每个日期分组 table 内**独立执行，主行与附属行（若有）成对移动。

### 3.4 百家平均列 — 指数类型与排序

> 本页该列被 CSS 隐藏，但 JS 逻辑完整，切换玩法页或取消隐藏后可用。

**指数类型选择**（`#exp_box` 单选）：

| 类别 | data-type 值 | 可选来源 |
|------|--------------|----------|
| 欧赔 | `europe_avg/wl/lb/bet365/hg` | 平均、威廉、立博、bet365、皇冠 |
| 亚盘 | `asian_am/lb/bet365/hg` | 澳门、立博、bet365、皇冠 |
| 概率 | `gl_avg/wl/am/lb/bet365/hg` | 平均、威廉、澳门、立博、bet365、皇冠 |
| 凯利 | `kl_avg/wl/am/lb/bet365/hg` | 平均、威廉、澳门、立博、bet365、皇冠 |

指数数据 AJAX 加载：

- 当日：`https://www.500.com/static/public/jczq/xml/odds/odds.xml`
- 历史：`.../hisdata/{年}/{月日}/odds.xml`（`#date` 有值时）

**排序菜单**（随指数类型动态变化）：

| 指数类 | 可排序字段 |
|--------|------------|
| 欧赔 | 场次号、主胜赔、客胜赔、主客差值 |
| 概率/凯利 | 场次号、主胜、平局、客胜 |
| 大小球 | 场次号、大球指数、小球指数 |

### 5.3 各列展示与交互

#### 编号列（td-no）

- 显示 `data-matchnum`（如周二001）。
- 点击 `a.bet-evt-hide` → 手动隐藏该场，隐藏计数 +1，已选号清除。

#### 赛事列（td-evt）

- 联赛彩色标签，背景色按联赛区分。
- 链接至 `liansai.500.com/zuqiu-{seasonid}/`。

#### 时间列（td-endtime）

- 默认显示截止/开赛时间（见 §3.2）。
- `title` 悬停显示完整提示。

#### 对阵列（td-team）

| 元素 | 说明 |
|------|------|
| `[n]` | 联赛排名（有数据时显示） |
| 队名链接 | 跳转 `liansai.500.com/team/{id}/` |
| `VS` | 未开赛显示 |
| `team-bf` + 比分链接 | 已完赛场次显示比分（如 `0:0`），链至数据页 |
| `ico-dg` 单关 | 该场胜平负玩法开售单关时显示 |

#### 让球列（td-rang）

两行对应不让球 / 让球：

| 行 | 类名 | 显示 | 颜色 |
|----|------|------|------|
| 不让球 | `itm-rangA1` | `0` + 可选单关标 | 默认 |
| 让球 | `itm-rangA2` | `+N` 或 `-N` | 红色=客让，绿色=主让 |

`title` 提示「不让球」「主队让N球」「客队让N球」。

#### 赔率列（td-betbtn）

两行赔率按钮：

| 行 | 类名 | data-type | 含义 |
|----|------|-----------|------|
| 上 | `itm-rangB1` | `nspf` | 胜平负（不让球） |
| 下 | `itm-rangB2` | `spf` | 让球胜平负 |

每个按钮（`p.betbtn`）：

| 属性 | 值 | 说明 |
|------|-----|------|
| `data-type` | `nspf` / `spf` | 玩法 |
| `data-value` | `3` / `1` / `0` | 胜 / 平 / 负 |
| `data-sp` | `2.13` | 固定奖金 SP |

**按钮状态类**：

| 类名 | 含义 |
|------|------|
| （默认） | 未选中 |
| `betbtn-on` | 用户已选入投注单 |
| `betbtn-ok` | 已完赛场次的中奖选项高亮 |

**点击交互**：

1. 切换 `betbtn-on` 选中态。
2. 写入 `BetModel`（胜/平/负 + SP）。
3. 触发抛物线动画飞入底部选号面板（`Parabola`）。
4. 单方案最多选 **15 场**，超出弹窗提示。

同一场可同时选胜平负与让球胜平负的不同选项（过关时）。

#### 数据列（td-data）

| 链接 | 目标 | 说明 |
|------|------|------|
| 析 | `odds.500.com/fenxi/shuju-{fixtureid}.shtml` | 赛事数据 |
| 亚 | `.../yazhi-{fixtureid}.shtml` | 亚盘 |

| 荐 | `.../youliao-{fixtureid}.shtml` | 有料推荐；有内容时 `tdQing` 红色显示，否则 `hide` |

#### 百家平均列（td-pei）

- 三个 `<span>` 分别显示主/平/客指数。
- 随 `ExpMenu` 切换类型异步填充；无数据为 `-`。
- **本页通过 CSS `display:none` 隐藏**（见 §8）。

## 6. 赔率相关动态功能

### 6.1 定时 SP 刷新（SPUpdate）

| 项目 | 值 |
|------|-----|
| 轮询间隔 | 5 分钟 |
| 数据源 | `/static/public/jczq/newxml/pl/pl_{0,1}_2.xml` |
| 覆盖玩法 | `spf`、`nspf` |
| 匹配键 | `{matchdate}\|{processname}` |

刷新逻辑：

1. 解析 XML 中每场 `<m>` 的 `<row>` 属性（win/draw/lost 及涨跌 w/d/l）。
2. 触发 `update_sp_ok` 事件。
3. 对比 `data-sp`：上涨标红 + `↑`，下跌标绿 + `↓`。
4. 若该选项已选中，同步更新 `BetModel` 中的 SP。

### 6.2 奖金变化浮层（livetip）

前置条件：勾选「显示奖金变化浮层」（`#filter_jjfc`）。

| 步骤 | 行为 |
|------|------|
| 鼠标进入 `div.betbtn-row` | 延迟 300ms 请求历史 SP |
| 请求接口 | `/interface/request.php?q=public.readfile&step=readpl` |
| 参数 | `playid`（269/354）、`zxid`（data-id）、`date` |
| 缓存 | 按 `zxid+playid` 缓存，有效期内不重复请求 |
| 渲染 | `#split_tmpl` 模板：胜/平/负 SP + 涨跌箭头 + 更新时间 |
| 定位 | 跟随鼠标，靠近屏幕底部时向上弹出 |
| 鼠标离开 | 隐藏浮层 |

让球行悬停时 `isrq=true`，表头显示「(让球)」标识。

## 7. 排序机制

所有排序在**每个日期分组内**独立进行，不改变分组之间的顺序。

### 7.1 奖金排序（sortBySpf）

- 按指定 `nspf_3` / `spf_0` 等键的 SP 值排序。
- SP 相同时按原始 `index` 稳定排序。
- 排序时主行 `tr` 与 `other` 附属行成对移动。

### 7.2 指数排序（sortByExp）

- 按当前选中指数类型的主/平/客值排序。
- 无指数数据的场次排到后面（用 `9e9 + index` 作为 fallback）。

> 以下配置针对 `playid=269`（胜平负/让球）页面；混合过关页差异见 §12。

## 12. 混合过关页 — 「展开更多玩法」扩展行

> 分析页面：[https://trade.500.com/jczq/?playid=312&g=2](https://trade.500.com/jczq/?playid=312&g=2)  
> 前端脚本：`ht.js`（混合过关专用，逻辑基于 `DgSelector`，与 `spf.js` 同源）  
> 玩法 ID：`playid=312`，`isgg=2`（过关）

### 12.1 与胜平负页的差异

| 对比项 | 胜平负/让球（`spf.js`） | 混合过关（`ht.js`） |
|--------|-------------------------|---------------------|
| URL | `?playid=269&g=2` | `?playid=312&g=2` |
| `noMoreOptions` | `true`（强制关闭） | 未设置（默认 `false`，启用扩展行） |
| 表头列数 | 8 列 | **9 列**（多「更多玩法」） |
| 胜平负列宽 | 315px | 244px（为更多列让位） |
| 每场 DOM 行数 | 1 行 `bet-tb-tr` | **2 行**：主行 + `bet-more-wrap` |
| 主行按钮 | `p.betbtn` | 同左 |
| 扩展行按钮 | 无 | `p.sbetbtn` |
| 单场数据模型 | `nspf` + `spf` | 另增 `bf` / `jqs` / `bqc` / `dxq` |
| SP 轮询 | `spf` + `nspf` | 同左（扩展玩法 SP 随页面 SSR，未纳入 5 分钟轮询） |

### 12.2 DOM 结构（双行成对）

每场比赛由相邻两行组成，JS 通过 `data.other = cur.next()` 绑定：

```
tr.bet-tb-tr              ← 主行：编号、联赛、时间、对阵、让球、胜平负 SP、更多按钮、数据、百家
tr.bet-more-wrap.hide     ← 扩展行：colspan 跨列，内含 div.bet-more
    └── table.bet-more-tb × N   ← 按玩法分块（半全场 / 比分 / 进球数）
```

主行新增 **「更多玩法」列**（`td-more`）：

```html
<td class="td td-more">
  <span class="bet-more-btn">
    <span class="bet-more-btn-txt">展开</span>
    <span class="ico-drop2"></span>   <!-- 下拉箭头 -->
    <span class="ico-chked"></span>   <!-- 扩展区有选号时显示 -->
    <s></s>
  </span>
</td>
```

表头对应 `th.th-other`（文案：「更多玩法」）。

### 12.3 展开/收起交互（toggleMoreOptions）

| 状态 | 按钮文案 | CSS 类 | 扩展行 |
|------|----------|--------|--------|
| 默认收起 | 展开 | — | `bet-more-wrap.hide`（`display:none`） |
| 已展开 | 收起 | `bet-more-btn-active` | 显示 |
| 扩展区有选号 | （文案不变） | `bet-more-btn-on` | `ico-chked` 勾选图标可见 |

交互细节：

1. 点击 `span.bet-more-btn` 切换展开/收起。
2. 展开时调用 `showFullMoreContent()`：若扩展区底部超出视口，页面自动下滚 400ms 动画，保证内容完整可见。
3. 收起时触发 `resetBottomOverTop`，重算底部选号面板位置。
4. **允许多场同时展开**（`hideOtherMore` 逻辑当前为 `if (false)`，不会自动收起其他场）。
5. 手动隐藏主行（`bet-evt-hide`）时，主行与扩展行一并隐藏；筛选器隐藏时同理（`data.trs` 成对操作）。
6. 排序时主行与扩展行成对移动，保持相邻关系。

### 12.4 扩展区玩法与选项

扩展区由服务端按场次 `data-subactive` 渲染，仅开售的玩法出现对应 `table.bet-more-tb`。`tr[data-subactive="1"]` 表示该玩法本场可售。

#### 半全场（`data-type="bqc"`，playid=272）

### 12.6 混合过关选号规则

与胜平负页共用 `BetModel` 与 `CodeList`，但有以下混合过关特性：

| 规则 | 说明 |
|------|------|
| 场次上限 | 单方案最多 **15 场**（按 `guid` 计，非按选项数） |
| 同场多选 | **允许**同一场选择多个玩法、多个选项（如同时选胜平负「胜」+ 比分「2:1」） |
| 选号面板展示 | 同场多选项合并在同一行 `td-chked`，以 `选项@SP` 链接展示，可逐个删除 |
| 玩法名称 | 胜平负显示「胜/平/负」；让球加 `[+N]` 前缀；半全场「胜胜」；进球数「7+」；大小球「大/小」 |
| 已选标记 | `isMoreEmpty(betData)` 为 false 时（`bf`/`jqs`/`bqc` 任一有值），`bet-more-btn` 加 `bet-more-btn-on` |
| 隐藏/筛选 | 扩展区选号随主行筛选一并清除（`removeByBets`） |

### 12.7 奖金变化浮层对扩展区的支持

开启「显示奖金变化浮层」后，悬停 **主行** `div.betbtn-row` 可查看胜平负 SP 历史；扩展区 `sbetbtn` 未绑定 `mouseenter` 事件，**不支持**悬停查看扩展玩法 SP 历史（扩展玩法 SP 以页面加载时 SSR 值为准）。

### 12.9 实现要点（复刻参考）

若在本项目复刻混合过关列表，需额外实现：

1. **双行成对渲染**：主行 + 可折叠扩展行，`colspan` 与列数对齐。
2. **`toggleMoreOptions` 状态机**：展开/收起/已选标记三态。
3. **`sbetbtn` 与 `betbtn` 统一选号管道**：共用 `BetModel.addItem`，区分 `data-type`。
4. **同场多玩法数据结构**：`{ nspf: {}, spf: {}, bf: {}, jqs: {}, bqc: {}, dxq: {} }`。
5. **排序/筛选/隐藏时成对操作**：`data.trs = other.add(tr)`。
6. **按 `subactive` 控制玩法块可见性**：未开售玩法不渲染对应 `bet-more-tb`。
