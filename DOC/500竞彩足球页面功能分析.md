# 500彩票网 — 竞彩足球页面功能分析

> 分析对象：[https://trade.500.com/jczq/](https://trade.500.com/jczq/)  
> 默认落地页标题：竞彩足球让球胜平负（数据资讯）  
> 分析日期：2026-08-25（初稿） / **2026-09-07（全玩法 + 动态接口 + 筛选谓词/投注串/采集对照补全）**  
> 说明：500 网仅提供数据和内容展示，页面本身无直接购彩功能；赛果以全场 90 分钟为准（含伤停补时，不含加时赛及点球）。  
> 复核范围：默认让球胜平负、单关、混合过关、比分、总进球、半全场，以及独立入口冠亚军（`/gyj/`）；源码编码为 `gb2312`/`gb18030`；动态行为依据 `jcbase.js` / `spf.js` / `jcprize.js` / `header.js`。

| 项目 | 说明 |
|------|------|
| 主域名 | `trade.500.com` |

## 5. 各玩法投注区差异（核心）

### 5.1 胜平负 / 让球胜平负（默认，`playid=269`）

| 区域 | 内容 |
|------|------|
| 让球列 | 两行：不让球 `0` + 让球数（绿=主让「-」，红=客让「+」） |
| 胜/平/负 | 两行 `.betbtn`：`data-type=nspf`（不让球）与 `data-type=spf`（让球） |
| 选项编码 | `data-value`：`3` 胜 / `1` 平 / `0` 负；`data-sp` 为当前固定奖金 |
| 单关标 | 支持单关的玩法行显示 `ico-dg`「单关」 |
| 排序 | 胜/平/负列均可：默认 / 高低排序 / 让球侧高低排序 |
| 数据列 | 析 / 亚 / 欧 / 荐 |
| 百家平均 | 欧赔 / 亚盘 / 概率 / 凯利多来源（见 §7.3） |

投注提示（面板旁）：

1. 让球只适合「让球胜平负」；`+` 客让主，`-` 主让客  
2. 过关固定奖金仅供参考，以投注成功为准；展示金额按每 1 元对应奖金  
3. 完场展示的过关奖金为截止时最终变化值，仅供参考  
4. **单注奖金上限**：单关 10 万；2～3 关 20 万；4～5 关 50 万；6 关及以上 100 万  
5. 单注奖金不足 2 元补足至 2 元  
6. 可交易时间（见 §9.3）

### 5.2 单关（`playid=312&g=1`）

- 主表结构接近混合：胜平负/让球 + **更多玩法**（半全场、比分、进球数可展开）  
- 筛选项**无**「只看单关」（本页本即单关视图）  
- 底部过关方式**仅「单关」**；可选「设倍数」  
- 仍保留析亚欧荐、百家指数等数据能力  

### 5.3 混合过关（`playid=312&g=2`）

- 主行：让球 + 胜/平/负（含排序）  
- 列「**更多玩法**」：展开后可选半全场、比分、进球数等（与单关展开同类）  
- 过关方式：单关 + 2串1～8串1 + 复合串（见 §8.2）；串关上限受所选玩法中**关数限制最低者**约束（体彩「木桶原则」）  
- 表单字段 `ismix` 存在（默认 `0`），用于标记混合方案  

### 5.4 比分（`playid=271`）

每场固定 **31** 个选项（复核）：

| 分组 | 选项 |
|------|------|
| 主胜比分 | `1:0` `2:0` `2:1` `3:0` `3:1` `3:2` `4:0` `4:1` `4:2` `5:0` `5:1` `5:2` + **胜其它** |
| 平局比分 | `0:0` `1:1` `2:2` `3:3` + **平其它** |
| 客胜比分 | `0:1` `0:2` `1:2` `0:3` `1:3` `2:3` `0:4` `1:4` `2:4` `0:5` `1:5` `2:5` + **负其它** |

表头「投注区」；无双行让球列。数据列与百家指数仍在。

### 5.5 总进球 / 进球数（`playid=270`）

| 表头 | `0球` `1球` `2球` `3球` `4球` `5球` `6球` `7+球` |
|------|--------------------------------------------------|
| `data-value` | `0`～`7`（7 表示 7+） |

### 5.6 半全场（`playid=272`）

| 表头 | 胜胜 胜平 胜负 平胜 平平 平负 负胜 负平 负负 |
|------|----------------------------------------------|
| `data-value` | `3-3` `3-1` `3-0` `1-3` `1-1` `1-0` `0-3` `0-1` `0-0`（半场-全场；3/1/0=胜/平/负） |

### 5.7 大小球（隐藏）

- 子导航 `playid=406` 被 HTML 注释，前端默认不可点  
- 行属性仍可能出现 `dxqdg`/`dxqgg`；当前在售样本多为 `0`  
- 页面保留 `split_dxq_tmpl`（大小球奖金变化浮层模板），说明历史/预留能力仍在 JS 中

### 6.2 高级筛选（`filterMore` / `filterMoreBtn`）

| 维度 | 说明 |
|------|------|
| 联赛筛选 | 按联赛勾选，展示场次数；`data-seasonid` / `data-simpleleague`；全选 / 反选 |
| 让球筛选 | 按让球数过滤（如 `-1`、`1`）；胜平负/让球与混合页意义最大 |
| 日期筛选 | 按销售日星期分组（如「周一(8场)」） |

### 6.3 筛选谓词（JS 实现）

勾选后向 `hides[]` 压入谓词，命中则隐藏该行：

| 筛选项 | 保留条件（不隐藏） | 实现要点 |
|--------|--------------------|----------|
| 五大联赛 | `simpleleague` ∈ {英超, 意甲, 西甲, 德甲, 法甲} | 源码为逗号串 `indexOf`（**不含欧冠/欧联**） |
| 奖金1.6倍以下 | `getMinSp() ≤ 1.6` | 大于 1.6 的场次隐藏 |
| 只看单关 | `isdgView === true` | 即行属性 **`data-kdg == "1"`**（与 `subactive` 各玩法 `*dg` 是两套标记） |
| 只看热门 | `ishot === true` | 行数据上的热门标记 |
| 已截止 | 见右 | 当 `#date` 为空且**未**勾选「已截止」时，隐藏 `isend === "1"`；勾选后才显示已截止场 |
| 联赛/让球/日期高级筛 | 未勾选项对应场次隐藏 | 反选逻辑：checkbox 未 `chkbox-on` 则过滤掉该维 |

> 说明：截止态同时由行属性 `data-isend`、交易时段弹层 `#fl-pop-end` 处理；勿因默认 HTML 无「已截止」勾选框就认定能力已下线。

### 7.6 赛事行数据属性（data-*）

每行 `<tr class="bet-tb-tr">` 携带元数据（复核字段）：

```
fixtureid, infomatchid, homesxname, awaysxname, matchdate, matchtime,
rangqiu, simpleleague, id, homeid, awayid, matchid, processid, processdate,
isshow, processname, buyendtime, isactive, subactive, matchnum, isend, kdg
```

JS 模型还会用到 `yszq`（大小球预设总分相关，用于混合/比分与大小球互斥校验；列表 HTML 上不一定露出）。

| 字段 | 含义（采集相关） |
|------|------------------|
| `fixtureid` | 500 场次主键；拼 fenxi URL |
| `id` | 资讯/指数侧 ID；SP 浮层请求里作 `zxid` |
| `processid` / `processdate` / `processname` | 销售过程；`processname` 如 `1001` 对应场次序号编码 |
| `matchnum` | 展示编号（如「周一001」） |
| `rangqiu` | 让球（整数；主让为负、客让为正，与 UI 颜色一致） |
| `kdg` | **`1` = `isdgView`**，供「只看单关」筛选；对阵区「单关」图标也参考 `subactive` 的 `*dg` |
| `subactive` | 各玩法单关/过关开关（见下表） |
| `isend` | `1` 已截止/完赛向；完赛行可能出现 `.team-bf` 比分链 |
| `buyendtime` | 投注截止时间 |

`subactive` 标明各玩法是否支持单关/过关，例如：

| 键 | 含义 |
|----|------|
| `nspfdg` / `nspfgg` | 胜平负 单关/过关 |
| `spfdg` / `spfgg` | 让球胜平负 单关/过关 |
| `bfdg` / `bfgg` | 比分 |
| `jqdg` / `jqgg` | 进球数 |
| `bqdg` / `bqgg` | 半全场 |
| `hcdg` / `hcgg` | 混合过关 |
| `dxqdg` / `dxqgg` | 大小球（本页多数场次为 0） |

示例（意甲 卡利亚里 vs 莱切）：

`bfdg:1,bfgg:1,bqdg:1,bqgg:1,dxqdg:0,dxqgg:0,hcdg:1,hcgg:1,jqdg:1,jqgg:1,nspfdg:0,nspfgg:1,spfdg:0,spfgg:1`

### 11.6 玩法 ID 映射与投注串（`codes`）

前端 `name2Playid` / `playid2Name`：

| `data-type` / 短名 | `playid` | 备注 |
|--------------------|----------|------|
| `spf` | 269 | 让球胜平负 |
| `nspf` | 354 | 胜平负 |
| `jqs` | 270 | 总进球（UI 文案「进球数」） |
| `bf` | 271 | 比分 |
| `bqc` | 272 | 半全场 |
| `ht` | 312 | 混合/单关页 |
| `dxq` | 406 | 大小球（入口隐藏） |

**`codes` 串格式（多场用 `/` 连接）：**

- 解析正则：`/(\d+\|\d+)(?:\|(\d+))?\[([^\]]+)\]/`  
  即：`{head}|{可选playid}[{选项列表}]`，选项逗号分隔  
- 非混合（`playid != 312`）提交前会去掉串里的 `|playid`，只保留选项括号段  
- 比分「其它」编码：`胜其它→3A`、`平其它→1A`、`负其它→0A`（`bfOther`）；半全场提交时去掉 `-`  
- 并行的 `ratelist`：选项写成 `值#SP`，结构与 codes 类似，供 `getbonusrange`  

示例形态（示意）：`1001|269[3,1]/1002[0]`（具体 head 以页面组装为准）。
